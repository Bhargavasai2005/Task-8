# Task 8 – Simple Sales Dashboard Design (Data Analyst Internship)

## 📊 Objective
To design an interactive dashboard using Power BI that showcases sales performance by **product category**, **region**, and **monthly trends**.

## 🛠 Tools Used
- Power BI Desktop
- Sample Dataset: `Superstore_Sales.csv`

## 📁 Dataset Overview
The dataset includes the following columns:
- **Order Date** – Date of purchase
- **Region** – Sales region (East, West, Central, South)
- **Category** – Product category (Furniture, Technology, Office Supplies)
- **Sales** – Revenue generated
- **Profit** – Profit earned per order

## 📈 Dashboard Visuals
The Power BI dashboard includes:
- **Line Chart**: Total Sales over time (Order Date)
- **Bar Chart**: Sales by Region
- **Donut Chart**: Sales by Product Category
- **Slicer**: Interactive filter by Category

## 💡 Insights
1. **Technology** contributed the highest share of sales (~36%), showing it as the most popular category.
2. The **East region** recorded the highest overall sales among all regions.
3. Monthly sales trends showed several spikes, indicating seasonal demand or sales campaigns.

- `Superstore_Sales.csv` – Sample dataset
- `Dashboard_Screenshot.png` – Power BI dashboard image
- `sales_insights.txt` – 3 Key insights
- `README.md` – This documentation

- Gained hands-on experience in Power BI
- Built a clean, interactive dashboard to communicate business performance effectively
